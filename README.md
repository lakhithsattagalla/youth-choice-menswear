# Youth Choice Mens & Womens Wear

> **Define Your Style. Wear Your Confidence.**

Contemporary fashion e-commerce platform built with React, Vite, Tailwind CSS, TypeScript, and Express backend featuring WhatsApp direct ordering, UPI QR code payments, and full admin dashboard.

---

## 🌟 Key Features

* **Instant Customer Ordering & Checkout:** Direct checkout with structured WhatsApp order payload & scannable UPI QR code.
* **Streamlined Direct Login & Registration:** Quick email/phone & password login without friction.
* **Official Branding:** Integrated Youth Choice YC Feather logo across header, cards, and footer.
* **Admin Executive Portal:**
  * Products Management (CRUD with color & size variants)
  * Stock & Inventory Matrix
  * WhatsApp Order Tracking & Status updates

## 🚀 Quick Start (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
* **Client App:** `http://localhost:5173/`
* **Admin Login Portal:** `http://localhost:5173/admin/login`
* **Backend Server:** `http://localhost:5000/api`

### 3. Build for Production
```bash
npm run build
```
